# 건설 영역과 부대 선택

## 울타리

나무·돌 울타리는 다른 건물과 중심 간격 **1칸**까지 설치할 수 있다. 기존 1.5칸 간격을 줄였다. 같은 칸에 겹쳐 설치할 수 없으며 일반 건물끼리는 기존 2.15칸 간격을 유지한다.

## 훈련소 비용 안내

인간을 선택하고 아군 일반·아처·브루저 훈련소에 마우스를 올리면 그 건물 위에 훈련 가능 인원과 총비용이 뜬다. 자원이 부족하면 비용을 붉게 표시한다.

- 1명당 나무 15, 돌 8, 구리 4, 철 3, 미네랄 1.
- 일반 훈련소는 주민만, 전문 훈련소는 일반 병사만 계산한다. 주민 → 일반 병사 → 브루저 또는 아처 순서로 훈련한다.
- 이미 훈련 대기·진행 중인 인간, 전문 병과, 소환물, 적 유닛과 사망한 유닛은 제외한다.
- 표시는 서버 훈련 접수와 같은 `훈련가능유닛` 규칙을 사용한다. 클릭 시 기존 FIFO 훈련과 자원 예약 규칙이 적용된다.

## 선택한 그룹에서 병과만 선택

화면 아래 선택 막대에서 **주민 / 병사 / 브루저 / 아처**를 클릭한다. 단축키는 각각 `Z`, `X`, `C`, `V`이다. 지도 전체가 아니라 현재 선택한 인간들 안에서 고른다. 병사는 전문 병과와 소환물을 제외한 일반 병사이다.

필터를 바꾸면 처음 선택했던 그룹을 기준으로 해당 병과를 다시 선택한다. **선택 복원**은 살아 있는 아군을 원래 그룹으로 되돌린다. 새로 드래그·클릭·Tab 선택을 하면 새 그룹을 기준으로 한다. Tab 전체 병력 선택은 유지된다. 건물 배치 중에는 부류 선택 단축키를 잠시 비활성화하고, 울타리 배치 중 V는 기존 회전 기능으로 동작한다.

## 깃발

- 건축 메뉴 **B 깃발**, 또는 `B`로 배치한다.
- 비용 나무 35·돌 10, 체력 180, 건설 시간 6초. 기본 한도는 진영당 2개이며 골렘 시련의 무작위 보상으로 1개씩, 최대 4개까지 늘어난다. 나무·돌 울타리의 합산 한도는 기본 12칸이고 시련 보상으로 최대 16칸이 된다.
- 회관이나 완공된 아군 깃발 반경 8칸 안에 설치할 수 있다. 완공되면 깃발 중심의 반경 8칸이 건설 영역에 추가된다. 다른 깃발을 이어 설치할 수 있다.
- 미완공·파괴된 깃발이나 적 깃발은 건설 영역을 주지 않는다. 이미 건설한 다른 건물을 철거하지는 않는다.
- 건설 중에는 회관·깃발의 영역 경계와 그 안의 탐사된 건설 격자를 표시한다. 지형·자원·시련·건물 간격 제한도 적용된다.
- Main 씬에 깃발 렌더러 8개와 메뉴 버튼 프리팹을 직접 배치했다. 런타임에 새 깃발 GameObject를 만들지 않는다.
- Aseprite 원본: `ArtSource/DivineWar_Flags_LowPoly_8Dir.aseprite`. Unity PNG: `Assets/DivineWar/Resources/Buildings/flags.png`.

## 검증과 네트워크

`DivineWar/Validation/Building Interaction`는 배치 참조, 울타리 간격, 깃발 건설·완공·영역 확대·파괴·진영·제한, 세 훈련소의 대상 계산, 병과 필터와 스냅샷 왕복을 검사한다. 결과: `Temp/BuildingInteraction/results.txt`.

Play Mode의 `DivineWar/Building Interaction` 미리보기 메뉴는 기존 슬롯과 임시 전투 상태로 버튼 콜백·비용 표시를 확인한다. 종료 시 Play Mode를 나와 복원한다. 기존 시설·훈련·시련·선택 검증도 함께 실행한다.

네트워크 프로토콜은 **8**이다. 서버와 클라이언트를 같은 버전으로 빌드해야 한다. 두 클라이언트 실제 접속과 Player 빌드는 이번 변경에서 검증하지 않았다.
