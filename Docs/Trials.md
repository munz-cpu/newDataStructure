# 맵 시련

Main 씬의 `맵 시련` 아래에 시련석 6개, 보스 렌더러 6개, 강타 예고 렌더러 6개를 직접 배치했다. 런타임에 시련 오브젝트를 생성하지 않는다. 해골 병사는 기존 병사 슬롯을 사용한다.

## 플레이

- 왕이 시련석 2.6칸 안에서 좌클릭 또는 우클릭하면 활성화된다. 장거리에서는 먼저 가까이 이동해야 한다.
- 1.5초 뒤 체력 650의 **망각의 파수꾼**이 등장한다. 보스를 클릭하면 왕이나 선택한 부대가 기존 전투 시스템으로 공격한다. 직업 스킬과 원거리 투사체도 적용된다.
- 보스는 근접 공격 24, 이동 속도 1.8이며, 5초 간격으로 반경 2.5칸의 강타를 1.2초 예고한다. 강타 피해는 55이다.
- 활성화한 진영의 왕·병사가 시련석 반경 9칸 안에 8초 동안 없으면 시련이 다시 봉인된다. 재도전 시 보스 체력이 초기화된다.
- 처치 후 왕이 시련석을 클릭하면 보상을 한 번 받는다. 활성화한 진영만 보스를 공격하고 보상을 획득한다. 보스는 전투 계산에서 상대 진영에 귀속되지만 별도 시련 슬롯을 사용한다.
- 골렘을 처치하면 서버가 가능한 보상 중 하나를 같은 확률로 무작위 추첨한다. 수령 전까지 결과가 유지되며, 시련석을 클릭해 한 번 받는다.
- **왕의 유물**: 힘 +4, 최대 체력 +40. 즉시 적용되고 경기 중 부활 후에도 유지된다. 유물끼리 중첩된다.
- **정예 해골 병사 3명**: 체력 180, 힘 11, 민첩 6, 지능 3. 일반 병사처럼 선택·이동·공격하며 시간 제한은 없다. 병력 정원 48과 훈련 예약 공간을 공유한다. 공간이 부족하면 보상은 시련석에 남아 있다.
- **깃발 최대 수 +1**: 기본 2개에서 최대 4개까지 늘어난다.
- **울타리 최대 수 +4**: 기본 12칸에서 최대 16칸까지 늘어난다. 나무·돌 울타리는 한도를 공유한다.
- 한도 증가는 보상을 받은 진영에만 경기 동안 적용되고, 왕의 부활 후에도 유지된다. 수령하지 않은 한도 증가 보상도 예약하여 최대치를 넘기는 보상은 추첨에서 제외한다. 건축 메뉴의 `현재 수 / 최대 수`에도 즉시 반영된다.
- 탐사한 시련은 미니맵에 금색으로 표시되며 전투 중에는 주황색으로 바뀐다. 시련석 주변 2.4칸에는 건설할 수 없다.

## 코드와 그림

- `전장시련.cs`: 서버 권한 활성화, 보스 AI, 이탈 초기화, 일회성 보상.
- `시련화면.cs`, `시련표식.cs`: 기존 입력·유닛 렌더링 연결, 안개, 체력 표시, 범위 예고. 상태는 기존 압축 스냅샷으로 전달한다.
- Aseprite에서 직접 만든 원본: `ArtSource/trial-stone.aseprite`, `trial-warden.aseprite`, `skeleton-soldier.aseprite`, `trial-warning.aseprite`.
- Unity PNG: `Assets/DivineWar/Resources/Trials/`. 보스·병사는 각각 8방향 × 대기/보행/공격 24프레임. `TrialArtImporter`가 Point 필터, 무압축, 바닥 피벗과 슬라이스를 적용한다.
- 멀티플레이 프로토콜 **8**. 클라이언트와 서버를 같은 버전으로 다시 빌드해야 한다. 실제 두 클라이언트 접속 검증과 플레이어 빌드는 이번 작업에서 수행하지 않았다.

## 검증

`DivineWar/Validation/Trials`는 실제 Main 지형을 사용해 배치 참조와 그림, 거리·중복 활성화·소환 지연, 보스 근접 공격·강타 회피·이탈 초기화, 실제 공격으로 처치 후 유물 획득과 부활 유지, 정원 부족 시 보상 보관·상대 수령 거부·해골 병사 생성, 압축 스냅샷 왕복을 확인한다. 결과는 `Temp/Trials/results.txt`에 기록된다.

Play Mode에서 `DivineWar/Trials/Prepare Play Preview`, `Preview Combat`으로 임시 시련 화면을 확인할 수 있다. 런타임 상태만 변경하며 Play Mode 종료 시 복구된다. 씬 참조를 다시 연결해야 할 때에는 Edit Mode에서 `Wire Authored Renderers`를 사용한다.
