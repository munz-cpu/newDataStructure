# DivineWar 왕 직업

타이틀에서 지휘관, 아처, 검사를 선택한다. 오른쪽에는 선택한 직업의 외형이 표시된다. 다음 표는 기존 저장 데이터와 전투 검증에서 사용하는 이전 직업의 기능을 기록한다.

| 직업 | 주요 전투 기능 |
| --- | --- |
| 트린다미어 | 잃은 체력 비례 공격, 치명타, 자가 회복, 공격 약화·등을 돌린 적 둔화, 회전 돌진, CC 중에도 쓸 수 있는 5초 불사 |
| 소라카 | 부상 아군 방향 이동 가속, 별부름 적중 회복, 아군 단일 치유와 체력 소모, 침묵 후 속박, 전역 아군 회복 |
| 애쉬 | 원거리 기본 공격과 서리 둔화, 집중 강화, 부채꼴 사격, 정찰 시야, 이동 거리에 따른 궁극기 기절 |
| 아지르 | 건물 유적의 태양 포탑, 모래 병사 소환·재배치, 병사 방향 돌진과 방패, 밀쳐내기와 적 통과를 막는 병사 벽 |
| 이블린 | 비전투 위장·저체력 회복, 가시 적중 후 추가 세 번 시전, 숙성하는 매혹 표식, 접근 공격, 저체력 대상 추가 피해와 후퇴 |
| 그라가스 | 스킬 사용 시 주기적 회복, 재폭발 가능한 술통, 피해 감소와 다음 공격 강화, 박치기 기절, 폭발 중심에서 바깥으로 밀쳐내기 |

| 헤카림 | 추가 이동 속도 비례 공격, 연속 회오리 베기, 주변 피해·회복, 가속 후 밀쳐내는 공격, 돌진 후 공포 |

## 게임에 맞춘 적용

- 마나, 분노, 열, 과열과 해당 자원 조건은 추가하지 않았다. 스킬은 쿨다운으로 사용한다. 체력이 이미 있는 게임이므로 소라카 W는 체력을 사용하며, 별부름 적중 후 소모가 줄어든다.
- 기본 공격이 원거리인 직업은 사거리가 다르다. CC는 병사·주민·왕에게 적용하며, 건물에는 적용하지 않는다. 기절은 이동과 공격, 속박은 이동, 침묵은 스킬을 제한한다. 공포와 매혹은 이동 방향을 강제한다.
- 소환물은 Main에 이미 배치된 병사 렌더러 슬롯을 사용한다. 병력 제한 48과 훈련 예약 공간을 공유한다. 새 GameObject를 생성하지 않는다. 모래 병사 최대 3명, 일반 포탑 최대 3개, 강화 포탑·태양 포탑·데이지는 종류별 최대 1개다.
- 지속 지대와 투사체는 최대 64개다. 기존 전장 오버레이로 표시한다. 소환물은 수명이 있고 공격받아 파괴될 수 있다. 포탑과 모래 병사는 왕에서 멀어지면 공격을 멈춘다. 태양 포탑은 독립적으로 작동한다.
- 수치와 판정은 DivineWar 규모에 맞춘다. 투사체가 있는 기술과 즉시 광역 판정 기술을 구분했으며 롤의 모든 프레임·레벨별 계수·애니메이션을 그대로 재현한 것은 아니다. 예를 들어 아지르 병사는 자동 공격하고 아이번 동물 해방은 채널링 없이 적용한다.

## 원본과 Unity 연결

- 타이틀과 전장의 플레이어 외형은 `Assets/Images/`의 원본 PNG와 기마 기사 스프라이트를 직접 참조한다. `PlayerAvatarImporter`가 원본 텍스처에서 스프라이트 영역, 발 위치 피벗, 표시 배율을 지정한다. 외형 목록은 `PlayerAppearances.hdavatars`에서 가져온다.
- 직업마다 대기·이동·공격을 E/SE/S/SW/W/NW/N/NE 순서로 연결한다. 각 방향은 기존 재생 방식에 맞춰 15프레임으로 배정한다. Unity 메뉴 `DivineWar/Art/Assign Supplied Characters`에서 목록을 다시 가져올 수 있다.
- `AssignedAppearances.asset`은 소환물 외형을 연결한다. 포탑과 강화 포탑은 같은 외형을 사용한다.
- `왕직업목록.cs`: 패시브 설명과 QWER 이름·설명·쿨다운·사거리.
- `왕직업전투.cs`: 전투 규칙의 partial 확장. 서버 권한 상태, CC, 스킬, 소환물, 지대·투사체를 처리한다.

## 멀티와 검증

프로토콜을 4로 올리고 직업 번호를 쉼표로 구분해 두 자리 직업 번호도 전송한다. 서버와 클라이언트는 함께 새로 빌드해야 한다. 압축 전 상태 한도는 512 KiB다. 최대 병력과 64개 지대를 채운 검증 상태는 296,522바이트였다.

Unity 메뉴 `DivineWar/Validation/Class Combat`은 Main 씬에서 직업 전투를 검사한다. 배치 실행은 `ClassCombatChecks.Batch`이며, 기존 주민 훈련·부대 선택 검사와 열 직업의 타이틀 설명 영역도 확인한다. 씬은 저장하지 않는다.

원본 외형 연결 후 Unity 컴파일, 전투 및 에셋 검사 1,590개, 장착 기술 검사 27개, 주민 훈련 11항목, 부대 선택 8항목이 통과했다. 세 직업의 타이틀 미리보기도 같은 외형을 참조하는지 검사했다.

## 기본 공격 구분과 적중

- 원거리: 애쉬(화살), 소라카(별빛), 아지르(모래), 하이머딩거(마법공학 탄), 아이번(씨앗). 사거리 안에서 공격을 준비한 뒤 실제 투사체를 발사하며, 투사체가 목표에 도착할 때 피해와 기본 공격 효과를 적용한다. 기본 화살에는 애쉬 궁극기의 기절이 적용되지 않는다.
- 근접: 트린다미어·이블린·그라가스·헤카림. 공격 준비 후 타격 시점에도 상대가 근접 사거리 안에 있어야 피해를 준다. 플레이어는 기본 공격 동작이 끝날 때까지 이동하거나 돌진할 수 없다. 기절·공포·매혹은 타격 준비를 중단시킨다. 침묵과 속박은 기본 공격 자체를 금지하지 않는다.
- 소환물: 모래 병사와 데이지는 근접, 포탑·강화 포탑·태양 포탑은 원거리다. 마을회관도 발사체로 공격한다. 야생동물 사냥도 직업의 근접·원거리를 따른다. 아이번은 기존처럼 야생동물을 공격하지 않는다.
- 공격 순번과 방향을 상태에 포함해 동작을 시작한다. 아처는 활을 당긴 뒤 화살을 놓는 원본 동작을 사용한다.
- 이미 발사한 탄은 발사자가 죽어도 날아간다. 대상이 죽거나 같은 슬롯을 새 대상이 재사용하면 이전 탄은 새 대상에게 피해를 주지 않는다. 타격 장식 이펙트는 진행 중인 투사체를 밀어내지 않는다.
